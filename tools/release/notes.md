The full game as a native Windows program: its code is C, with no 68000 emulation.

**You need your own ROM:** this download has no game data. Put your USA/Europe dump in a folder called `rom` next to `wbmw.exe`, named `Wonder Boy in Monster World (USA, Europe).md`. `READ-ME-FIRST.txt` has the details.

**Added, all optional:** widescreen, enemy health bars and damage numbers, talk zoom, four save slots with pictures, and rebindable controls.

Windows 64-bit. The program is not signed, so Windows may warn you on first run (**More info**, then **Run anyway**). Linux and macOS users can build from source (see the README).
